## 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 火山方舟API变更 | 高 | 封装VolcengineClient，隔离API差异；关注官方文档更新 |
| TOS上传失败 | 高 | 本地保留副本；失败时重试3次；报警通知管理员 |
| 大文件上传超时 | 中 | 分片上传；进度反馈；超时时间设为300s |
| SQLite并发瓶颈 | 中 | WAL模式；读写分离(读副本)；预留MySQL迁移方案 |
| 前端构建产物过大 | 低 | 路由懒加载；图片压缩；CDN加速(后续) |
